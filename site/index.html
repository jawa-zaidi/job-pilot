What it actually does

One round is: find, write, send, then keep chasing. You can press the button yourself, or leave JobPilot to run rounds on its own.

Finds jobs that fit

Pulls openings straight from company career pages and free job boards, scores each one against your CV, and drops duplicates, reposts and expired listings.

Rewrites your CV for each one

A version of your CV tailored to that specific job, then a second pass that strips out anything it invented, checked against what your real CV actually says.

Writes the message that goes with it

The covering email, written for that role and that company — not a template with the company name dropped into a gap.

Sends it — or hands it to you

Where the posting gives a recruiter address, JobPilot emails it from your own Gmail with the CV attached as a PDF. Where you have to apply on the company's own site, it lands in Needs you with everything written and ready to copy.

Chases the follow-ups

Nudges on days 3, 5 and 10, and stops the moment somebody replies. The timings are real dates, so they survive you closing the app or moving to a new computer.

Reads the replies, tells you what's working

Sorts incoming mail into good news and rejections, and gives you a one-minute read on which sources are actually replying and what is worth changing.

Getting it running

About five minutes, most of which is the computer doing things by itself. There is nothing to type into a terminal, and you are never asked for an API key to get started.

  1. Download the ZIP and unpack it

    Use the button above for your kind of computer. On a Mac, double-click the downloaded ZIP. On Windows, right-click it and choose Extract All — that step matters, because Windows will otherwise show you the inside of the ZIP as if it were a normal folder. Open the folder that appears.

  2. Start it — one double-click

    On a Mac: find JobPilot.command in the folder, right-click it, choose Open, then click Open again in the box that appears.

    Do not just double-click it the first time

    macOS will say JobPilot “cannot be opened because it is from an unidentified developer” and refuse to run it. That looks like the app is broken. It isn't — it is macOS being careful about software that hasn't been through Apple's paid signing process, which this project has not. Right-click → Open → Open is the way past it, and you only ever have to do it once.

    On Windows: double-click JobPilot.bat. Windows may show its own "unrecognised app" warning; choose More info → Run anyway.

  3. A plain window opens, and that's it

    A plain black window appears, says where your data folder is, and starts JobPilot — a couple of seconds, not a couple of minutes. Leave that window open: it is JobPilot running. Closing it, or pressing Ctrl+C in it, quits the app.

    There is nothing to install and nothing to sign up for at this point. The download already contains everything JobPilot needs, including its own copy of the program that runs it, so this step works with the wifi off and never asks for an admin password.

    This copy needs Node.js on the computer — it is free, and it is the only thing you have to install separately. If it isn't there, the window tells you so in plain words and opens the download page for you, so you never have to go looking. Install it, then double-click JobPilot again.

  4. JobPilot opens in Chrome

    It opens itself in its own Chrome window at localhost:4310 — that address is your own computer, not a website. If something else is already using that port, JobPilot quietly moves to the next free one and tells you which. If you don't have Chrome it opens in your normal browser instead and everything still works.

  5. Answer five questions

    One at a time, with a Skip link on every one: what to call you; your CV (drag the file in — PDF, Word or text); the kind of job you're after; where you'd like to work; and who presses send — JobPilot, or you.

    It shows you what it understood from your CV before anything else happens, so you can catch it being wrong early.

  6. Press the big button

    Its label always tells you what it will do next: Find my first jobs, then Write N applications, then Send N applications, and round again. The first time a run needs to read a job advert, JobPilot asks you to connect an AI writer — that is covered below.

Starting it after that

On a Mac, that first run creates a JobPilot.app next to the other files — double-click that from then on and there's no black window at all. You can drag it into your Applications folder. On Windows, the first successful run puts a JobPilot shortcut on your Desktop and in the Start Menu.

Keep it in your Dock

Optional, and it takes one click.

Once JobPilot is running, it offers to install itself as a proper app: a small bar appears at the top of the Home screen saying “Keep JobPilot in your Dock”. Press Install it, confirm Chrome's Install app? box, and you get a Dock or Taskbar icon and a clean window with no tabs and no address bar. Chrome's own menu does the same thing: ⋮ → Cast, save and share → Install page as app.

This is the window, not the engine. Your data lives on your computer and is served by JobPilot itself, so you still start it the normal way first — installing just gives you a nicer window to look at it in. Safari doesn't offer this; on iOS, Share → Add to Home Screen gets you the icon.

What it costs, what it needs

JobPilot itself is free and open source (MIT), and there is no account to make and nothing to pay the developer, ever. What it does need is somewhere to do the writing.

The AI writer — pick one

  • Already pay for Claude Pro or Max? Then there is nothing more to pay and no key to paste. JobPilot uses the Claude Code app you're already signed into on that computer. Honest caveat: it isn't free so much as included — it spends the same monthly usage allowance you use talking to Claude yourself, and a big batch gets through it quickly.
  • Otherwise, a free Groq key. Two minutes to set up, no card, and JobPilot gives you the link and a box to paste it into at the moment it needs one.
  • Or a paid OpenAI or Anthropic key, if you'd rather. Roughly a few dollars per hundred applications, and JobPilot logs what every round actually cost.

Everything else

  • A Mac or Windows computer. Not a phone or a tablet.
  • Nothing else to install. The download brings its own copy of Node.js, the free program that runs JobPilot, so there is no second installer and no admin password. If you already have Node.js, JobPilot uses yours instead. Node.js, installed once. Free. The launcher checks for it, explains it, and opens the download page if it's missing.
  • Gmail is optional. Connect it and JobPilot sends applications and follow-ups for you and reads the replies. Leave it out and JobPilot still writes every CV and every message — you just send them yourself. Nothing is worse for choosing that.
  • The job sources are free. Company career pages and the free boards need no key and no account, and career pages get the best replies anyway.

Your CV never leaves your computer

Not a marketing line — it is a consequence of how the thing is built.

  • There is no JobPilot server. You run the whole thing yourself. It listens on 127.0.0.1 — your machine only — so nothing else, even on your own home network, can reach it unless you deliberately turn that on.
  • Your data sits in one folder — JobPilotData in your home directory. Your CV, your applications, your history, all of it. Copy that folder to a new computer and everything is back. Delete it and JobPilot has nothing.
  • It only talks to the services you set up yourself — the AI provider you chose, your own Gmail, and the job boards you switched on. Your CV goes to your AI provider because that is the only way it can be rewritten; it does not go anywhere the developer can see.
  • Nothing is reported back unless you turn it on. There is an off-by-default setting that emails the developer aggregate counts — how many jobs were found, which sources, error categories, costs. No names, no companies, no job titles, no email contents. Because it sends from your own Gmail, the developer would see your address, so it is content-anonymous rather than fully anonymous. It stays off until you switch it on.
  • Even the typefaces are bundled. The app makes no call to a font CDN on launch, and works with the network unplugged.

Where it's up to

JobPilot is new — version 0.1 — and has not been tested end to end. It is worth knowing what is well-trodden and what isn't before you rely on it.

  • The Windows path is less tested than the Mac one. The Mac download has been unpacked and started from scratch on a machine with no Node.js on it at all, and it worked. The Windows build is made by the same script and reviewed line by line, but it has not been run on a real Windows machine. Expect to hit something.
  • No real application email has been sent yet. Saving your Gmail details, the test-send button and the failure messages all work; an actual application leaving an actual inbox has not been watched. Treat your first send as the test.
  • Pasted API keys are the least-travelled route. The Claude subscription path has been driven against a real signed-in setup and does produce real scoring and real writing. A pasted Groq, OpenAI or Anthropic key has not been run end to end.
  • The Chrome "Install app?" dialog hasn't been eyeballed. Everything up to the moment Chrome takes over is verified; the native box and the resulting Dock icon are not.
  • macOS will not open it without the right-click step, because there is no paid Apple signing certificate behind this project. A signed build is on the list.

If you hit something, the code is all there — open an issue on GitHub and it can be fixed.
